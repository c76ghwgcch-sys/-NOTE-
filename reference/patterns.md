# 状況の分かれ方 20パターン
テーマごとに、いちばん手順が変わる軸を1つ選び、3つに分ける。
（4つの軸を全部入れる→読めない／2つしかない→100円の商品になる）

## 軸1：規模
1. 1人でやる場合 / 数人でやる場合 / 部署全体の場合
2. 1件だけ / 10件程度 / 100件以上
3. 今回だけ / 毎月ある / 毎日ある
4. 個人で完結 / 社内の承認が要る / 社外が絡む
5. 金額が小さい / 稟議が必要な額 / 役員決裁の額

## 軸2：時期
6. 期限まで余裕がある / 今週中 / 今日中
7. 始まる前 / 進行中 / 終わったあと
8. 年度の始め / 途中 / 年度末
9. まだ何も始めていない / 途中で止まっている / やり直し
10. 初めて / 2回目以降 / 前任から引き継いだ

## 軸3：立場
11. 自分で決められる / 上司の承認が要る / 自分は実務だけ
12. 依頼する側 / 依頼される側
13. 正社員 / 契約や派遣 / 業務委託
14. 専任で担当 / 他の仕事と兼任
15. 聞ける人がいる / 誰もいない ← 500円を払う人の多くは「誰もいない」側

## 軸4：状態
16. 既存のものを直す / ゼロから作る
17. 前例がある / 前例がない
18. ツールが使える / 紙とメールだけ
19. 予算がある / 予算ゼロ
20. 社内ルールが決まっている / 決まっていない
