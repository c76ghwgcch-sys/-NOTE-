# 異動してすぐの2週間で、前任の仕事を把握する

## いま、こんな場面で止まっていませんか
異動して3日目。前任から渡されたのは、A4で1枚のメモだけです。フォルダを開くと、名前の分からないファイルが何百個も並んでいます。取引先からのメールには、知らない案件名が出てきます。誰に何を聞けばいいのかも分かりません。「そのうち慣れる」と言われても、来週の締切が何かすら分かっていない。この記事は、その状態から2週間で仕事の全体をつかむための手順です。

## この記事が向いていない人
- 前任と1か月以上いっしょに働いて、引き継ぎを受けられる人
- 異動先の仕事が、前の部署とほぼ同じ人
- 会社に決まった引き継ぎの手順書があり、それどおりに進められる人

## 全体像：2週間・4ステップで終わります
1. 1〜2日目：聞く相手の一覧を作る
2. 3〜5日目：前任のファイルとメールから、仕事を拾い出す
3. 6〜8日目：仕事を一覧表にして、年間の山場を見つける
4. 9〜10日目：一覧表を上司に見せて、抜けを埋める

1日にかける時間は1〜2時間です。ふだんの仕事と並行して進められます。

| ステップ | 終わったときに、手元にあるもの |
|---|---|
| 1 | 聞く相手10人の名前と、聞く順番 |
| 2 | 前任がやっていた仕事の名前の一覧 |
| 3 | 1年のうち、仕事が集中する月 |
| 4 | 上司が確認ずみの、仕事の一覧表 |

2週間たっても全部の仕事ができるようにはなりません。目指すのは、**何があるかを全部知っていて、近いものから順にできる状態** です。

## 有料部分に入っているもの
- 前任が「社内にいる」「退職している」「いない(新設)」の3つの場合で、何を変えるか
- 聞く相手を決める順番と、最初の声のかけ方
- 前任のフォルダとメールの掘り方(検索する言葉の例つき)
- 年間の山場の見つけ方
- そのまま使える書式3つ：聞きたいことリスト／業務の棚卸し表／年間カレンダー
- 2週間で終わったかどうかの確認方法

ーーー ここから有料 ーーー

## 状況の分かれ方：前任がどこにいるかで、やり方が変わります

### Aの場合：前任が社内の別の部署にいる
いちばん恵まれた状況です。ただし、前任も新しい部署で忙しくしています。思いついたときに何度も聞くと、相手の負担になります。
やることは1つです。**聞きたいことを1週間ためて、30分だけ時間をもらう。** 書式1の「聞きたいことリスト」を使います。

### Bの場合：前任が退職している
直接は聞けません。代わりに聞く相手は、次の2人です。
- 前任といっしょに仕事をしていた同僚
- 前任とやりとりしていた取引先や他部署の担当者

この場合、ステップ2の「ファイルとメールを掘る」比重が大きくなります。前任のメールボックスが残っているかを、最初に上司に確認してください。会社によっては、退職と同時に消えていることがあります【要確認：自社のルール】。

### Cの場合：新しくできたポジションで、前任がいない
引き継ぐ相手がいません。代わりに「この仕事を作った人」に聞きます。多くは、あなたを異動させた上司です。
最初に聞くことは、「この仕事で、半年後に何ができていればいいですか」です。前任がいない場合は、仕事を拾うのではなく、決めていく作業になります。ステップ2は短く、ステップ4を長くとってください。

## ステップ1(1〜2日目)：聞く相手の一覧を作る

### やること
1. 前任のメールの「送信済み」フォルダを開きます(Bの場合は、上司に閲覧できるか確認してから)
2. 過去3か月分で、やりとりの多い相手を上から10人書き出します
3. 書式1の「聞きたいことリスト」の左の列に、その10人の名前を入れます

Outlookの場合は、「送信済みアイテム」を開き、上の「差出人/宛先」の列で並べ替えます。Gmailの場合は、左の「送信済み」を開きます【要確認：お使いのメールソフトの画面名】。

### 声をかける順番
1. 直属の上司(仕事の優先順位を知っている)
2. 同じチームで、いちばん長くいる人(過去の経緯を知っている)
3. 前任(Aの場合)
4. 他部署・取引先(仕事の受け渡しがある相手)

### 最初の声のかけ方
「○○さんから引き継いだ△△です。来週あたりで15分だけ、□□の件の流れを教えてもらえませんか」
ポイントは、**時間と聞きたいことを先に言う** ことです。何を聞かれるか分からないと、相手は身構えます。

[ここに体験]

## ステップ2(3〜5日目)：前任のファイルとメールから仕事を拾う

### フォルダの見方
全部を開く必要はありません。次の順で見ます。
1. 更新日の新しい順に並べ替える
2. 上から30個のファイル名を書き出す
3. 同じ名前で日付だけ違うファイルを探す(毎月・毎週の作業の跡です)

Windowsのエクスプローラーなら、上の「表示」から「詳細」に切り替えると「更新日時」の列が出ます。列の名前を押すと並べ替わります【要確認：Windowsのバージョンで表示が変わる】。

### メールで検索する言葉
メールソフトの検索窓に、次の言葉を1つずつ入れます。
- 「締切」「期限」「提出」→ 決まった日に出すもの
- 「毎月」「月次」「四半期」→ くり返しの作業
- 「承認」「確認お願いします」→ 誰かに見せる流れ
- 「請求」「支払」→ お金が動く作業(遅れると影響が大きい)

### 拾ったものの書き方
書式2の「業務の棚卸し表」に、1つの仕事を1行で書きます。この段階では、中身が分からなくてかまいません。**名前と、いつやっているかだけ** 埋めてください。

## 前任に30分もらえたときの聞き方(Aの場合)
30分は短いので、聞く順番を決めておきます。
1. 最初の5分：棚卸し表を見せて「抜けている仕事はありますか」
2. 次の15分：いちばん近い山場の仕事のやり方
3. 次の5分：「やっていて困ったこと」「やめたかったこと」
4. 最後の5分：「また聞きたいときは、チャットでいいですか」

3つ目の質問は、前任しか知らない情報です。マニュアルには書かれていない、取引先のくせや、社内の人間関係の注意点が出てきます。聞いた内容は、その日のうちに棚卸し表のメモに書きます。

## ステップ3(6〜8日目)：一覧表にして、年間の山場を見つける
棚卸し表の「時期」の列を見て、書式3の「年間カレンダー」に写します。
写すと、仕事が集中している月が見えます。これが山場です。

たとえば、棚卸し表の時期の列に「3月」が5つ、「9月」が3つ、ほかの月が1つずつあれば、3月と9月が山場です。山場の1〜2か月前は、準備の作業が始まる時期でもあります。カレンダーの「準備を始める月」の列も埋めてください。

山場が分かったら、**いちばん近い山場の仕事から、中身を確かめに行きます。** 半年先の仕事は、いまは名前だけで十分です。

## ステップ4(9〜10日目)：上司に見せて、抜けを埋める
棚卸し表と年間カレンダーを上司に見せて、次の3つを聞きます。
1. 「ここに入っていない仕事はありますか」
2. 「この中で、いちばん遅れてはいけないものはどれですか」
3. 「前任のやり方で、変えてほしいものはありますか」

3つ目を聞いておくと、あとで「勝手に変えた」と言われずに済みます。

[ここに体験]

## つまずきやすい箇所と、その対処
| つまずき | 対処 |
|---|---|
| ファイルが多すぎて、どこから見るか決められない | 更新日の新しい順に30個だけ見る。それ以外は後回し |
| 聞いた相手ごとに、言うことが違う | 棚卸し表の「メモ」に、誰が何と言ったかを書く。上司に見せるときにそのまま聞く |
| 取引先から、知らない案件で連絡が来る | 「確認して本日中にご連絡します」と返して、棚卸し表に追加する。その場で答えない |
| 1日目から仕事を頼まれて、把握に使う時間がない | 上司に「最初の2週間は、毎日1時間を引き継ぎの確認にあてたい」と先に伝える。時間を決めて予定表に入れておく |
| 前任のファイルにパスワードがかかっている | 自分で解こうとしない。上司か情報システムの担当に聞く |
| 前任の作業のやり方が分からない | 前任の過去のメールで、同じ時期に誰に何を送っているかを見る。送った物がやり方の手がかりになる |

## そのまま使える書式3つ

### 書式1：聞きたいことリスト(Aの場合に、とくに使う)
| 聞く相手 | 聞きたいこと | いつまでに | 聞いた答え |
|---|---|---|---|
| 前任 ○○さん | 月次報告の数字は、どこから持ってきているか | ○/○ | |
| 経理 △△さん | 請求書の締め日はいつか | ○/○ | |
| 上司 | いちばん遅れてはいけない仕事はどれか | ○/○ | |

### 書式2：業務の棚卸し表(Bの場合に、とくに使う)
| 仕事の名前 | いつやるか | 誰に渡すか | 使うファイル | 分かっている度 | メモ |
|---|---|---|---|---|---|
| 月次報告 | 毎月5営業日目 | 部長 | 月次_2026xx.xlsx | 名前だけ | |
| 請求書の確認 | 毎月25日 | 経理 | | 半分 | 経理△△さんに確認ずみ |

「分かっている度」は、「名前だけ」「半分」「1人でできる」の3段階で書きます。

### 書式3：年間カレンダー(Cの場合に、とくに使う)
| 月 | 決まった仕事 | 山場か | 準備を始める月 |
|---|---|---|---|
| 4月 | 年度計画の提出 | ◎ | 2月 |
| 9月 | 半期の振り返り | ○ | 8月 |
| 3月 | 予算の締め | ◎ | 1月 |

Cの場合は、「決まった仕事」の列を上司と相談しながら埋めます。

## 終わったかどうかの確認方法
次の4つに「はい」と言えたら、2週間の把握は終わりです。
- [ ] 棚卸し表に、仕事が15行以上ある
- [ ] いちばん近い山場の仕事が、「1人でできる」になっている
- [ ] 上司に棚卸し表を見せて、抜けを確認してもらった
- [ ] 取引先や他部署の担当者に、名前と連絡先を伝えた

## この手順が終わった人が、次に困ること
2週間で仕事の全体は見えます。次に困るのは、**前任のやり方を変えていいかどうか** です。効率の悪い作業が見えてきても、なぜそうしているのか理由が分からないことがあります。変える前に確かめる手順は、別の記事で書きます。
