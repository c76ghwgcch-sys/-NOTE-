# 歓送迎会・忘年会の幹事を任されたときの進め方

## いま、こんな場面で止まっていませんか
「今年の忘年会、幹事お願いね」と言われて1週間。まだ何も決まっていません。日にちを先に決めるのか、店を先に探すのか。全員に聞いたら意見がバラバラで、まとまらない気がする。部長の予定はどう押さえればいいのか。会費はいくらにすれば文句が出ないのか。去年の幹事に聞いても「適当で大丈夫だよ」としか言われない。この記事は、その状態から当日の締めのあいさつまで、迷わず進めるための手順です。

## この記事が向いていない人
- 会社に幹事の手順書や、決まった店がある人
- 総務やイベント会社が、店の手配までしてくれる人
- 参加者が5人以下で、その場の思いつきで決めても困らない人

## 全体像：5ステップで終わります
1. 6〜5週間前：日にちと予算の枠を決める
2. 5〜4週間前：店を決めて予約する
3. 4〜2週間前：案内を出して、出欠を取る
4. 1週間前〜前日：人数を確定して、当日の流れを作る
5. 当日〜翌日：進行と、会費の精算

| ステップ | 終わったときに、決まっていること |
|---|---|
| 1 | 日にちと、会費のおおよその額 |
| 2 | 店と、人数を変えられる締切 |
| 3 | 参加する人の名前 |
| 4 | あいさつをする人と、当日の時間割 |
| 5 | 会費の受け取りと、お礼の連絡 |

幹事の仕事のほとんどは、ステップ1と2で決まります。ここで日にちと店が決まれば、あとは連絡と確認だけです。

幹事にかかる時間は、全部合わせて3〜5時間ほどです。いちばん時間がかかるのは店探しで、2時間ほど見ておきます。逆に、出欠の確認や当日の準備は、表を1つ作っておけば15分ずつで済みます。

年末の忘年会は店が埋まりやすいので、1か月半前に動き始めるのが目安です【要確認：地域や時期で変わる】。

## 有料部分に入っているもの
- 10人以下／10〜30人／30人以上で、何を変えるか
- 日にちを決めるときに、先に押さえる人の順番
- 店を選ぶ条件(人数別)
- 出欠の取り方と、会費の決め方
- そのまま使える書式3つ：案内メールの文例／出欠と会費の管理表／当日の進行表
- 当日のドタキャンと、会費の過不足への対処

## 状況の分かれ方：人数で、やり方が変わります

### Aの場合：10人以下
いちばん身軽です。出欠はチャットで聞けば足ります。店はコース料理でなくても、席だけ予約して料理はその場で頼む形でも回ります。
気をつけるのは、**1人が欠けると1人あたりの負担が大きく変わる** ことです。会費は「目安○円、最終的に割り勘」と伝えておくと揉めません。

### Bの場合：10〜30人
いちばん多いパターンです。この記事の手順は、このBを基本にしています。
コース料理と飲み放題をつけるのが一般的です。出欠は書式2の管理表で取ります。あいさつをする人を、事前に決めておく必要があります。

### Cの場合：30人以上・部署合同
1人で回すのは無理です。**幹事を2〜3人にして、役割を分けてください。**
- 店と当日の進行の担当
- 出欠と会費の担当
- 余興・景品の担当(やる場合)

貸切できる店が必要になるので、ステップ2を1〜2週間早めます。

## ステップ1：日にちと予算の枠を決める

### 先に押さえる人の順番
1. いちばん上の役職の人(部長など)：あいさつをお願いする人
2. 主役(歓送迎会なら、異動する人・入ってくる人)
3. それ以外の全員

1と2の都合を先に聞き、候補日を3つにしぼります。全員に最初から聞くと、決まりません。

### 予算の枠
会費の目安は、去年の幹事に聞くのがいちばん確実です。分からない場合は、上司に「去年はいくらくらいでしたか」と聞きます。
会社から補助が出るかどうかも、ここで確認します【要確認：自社のルール】。補助があると、店の選び方が変わります。

## ステップ2：店を決めて予約する

### 店を選ぶ条件
| 条件 | Aの場合 | Bの場合 | Cの場合 |
|---|---|---|---|
| 会社からの距離 | 歩いて10分以内 | 歩いて10分以内 | 駅から近い |
| 席 | テーブル | 個室か半個室 | 貸切 |
| 料理 | その場で注文でも可 | コースと飲み放題 | コースと飲み放題 |
| 予約の締切 | 1週間前 | 2〜3週間前 | 1か月前 |

### 予約するときに、店に聞くこと
- 人数の確定は、何日前まで変えられるか
- 当日、人数が減ったときの料金はどうなるか(キャンセル料)
- 飲み放題の時間と、ラストオーダーの時間
- 支払いはまとめてか、個別にできるか

**2つ目のキャンセル料は、必ず聞いてください。** あとで会費の過不足の原因になります。

## 会費の決め方
会費は、次の計算で決めます。
1. 店のコース料金(1人あたり)を確認する
2. 会社からの補助があれば、1人あたりの額を引く
3. 主役の分を参加者で持つ場合は、その分を足す
4. 100円か500円の単位で切り上げる

例：コース5,000円、補助なし、主役2人の分を20人で持つ場合
5,000円 + (5,000円 × 2人 ÷ 20人 = 500円) = 5,500円

役職によって会費を変える会社もあります。その場合は、去年の額を上司に聞いて合わせます。勝手に決めると、あとで気まずくなります。

## ステップ3：案内を出して、出欠を取る
書式1の案内メールを送ります。出欠の締切は、店の人数確定の日より **3日前** にします。返事をしない人に、声をかける時間が要るからです。
返事は書式2の管理表に記録します。Bの場合は、出欠と同時に「アレルギーや苦手な食べ物」も聞いておくと、店への連絡が1回で済みます。

## ステップ4：人数を確定して、当日の流れを作る
1. 締切の翌日に、返事のない人へ個別に声をかけます
2. 人数を店に連絡します
3. 書式3の進行表を作って、あいさつをお願いする人に送ります

乾杯のあいさつと締めのあいさつは、当日いきなり頼まず、**1週間前までに本人に頼んでおきます。**

## 歓送迎会の場合：主役への記念品
送別会では、花束や記念品を渡すことがあります。用意するかどうかは、去年の例に合わせます。
1. 上司に「記念品は用意しますか」と確認する
2. 用意する場合は、会費に含めるか、別に集めるかを決める
3. 花束は、店に持ち込んでよいか予約のときに聞く
4. 前日までに受け取り、当日は店に預ける

渡すタイミングは、締めのあいさつの直前が一般的です。進行表に「記念品の贈呈」を1行足して、誰が渡すかも書いておきます。

## ステップ5：当日の進行と、会費の精算
- 開始15分前に店に着き、人数と席を確認します
- 会費は、入り口で受け取るか、事前に集めるかを決めておきます
- 終わったら、領収書を受け取ります(補助が出る場合は宛名を確認)

翌日に、主役と参加者へお礼のメッセージを送って終わりです。

### 当日の幹事の持ち物
- 出欠と会費の管理表(印刷したもの)
- おつりの小銭(1,000円札と500円玉を多めに)
- 会費を入れる封筒
- 店の電話番号と予約名のメモ
- 進行表

## つまずきやすい箇所と、その対処
| つまずき | 対処 |
|---|---|
| 当日にドタキャンが出た | 店のキャンセル料のルールを確認。会費は「欠席の連絡が前日までなら返す」など、案内の時点で決めておく |
| 会費が足りなくなった | 補助がない場合は、幹事がかぶらない。上の役職の人に相談する(多めに出してくれることが多い) |
| 会費が余った | 次回の幹事に引き継ぐか、主役への記念品にあてる。案内の時点で書いておくと揉めない |
| 出欠の返事が締切までに半分しか来ない | 締切の前日に、チャットで1回だけ再案内する。それでも来ない人には、個別に声をかける |
| 部長の予定がなかなか決まらない | 部長の予定を管理している人(秘書や課長)に聞く |

## そのまま使える書式3つ

### 書式1：案内メールの文例(Bの場合)
```
件名：【ご案内】○○部 忘年会(12/○ 金)出欠のお願い

お疲れさまです。今年の忘年会の幹事を担当します、○○です。
下記のとおり開催しますので、出欠を○/○(○)までにご返信ください。

日時：12月○日(金) 19:00〜21:00
場所：○○(○○駅から徒歩5分) 地図：URL
会費：○,○○○円(当日、受付で集めます)

・アレルギーや苦手な食べ物があれば、あわせてお知らせください
・前日までに欠席のご連絡をいただいた場合、会費はかかりません

よろしくお願いします。
```

### 書式2：出欠と会費の管理表(Aの場合は、出欠の列だけでも可)
| 名前 | 出欠 | 返事の日 | 食べ物の注意 | 会費 | 受け取り |
|---|---|---|---|---|---|
| ○○部長 | 出 | ○/○ | なし | ○円 | 済 |
| △△さん | 未返信 | | | | |

### 書式3：当日の進行表(Cの場合は、担当の列を足す)
| 時間 | やること | 担当 |
|---|---|---|
| 18:45 | 店に到着、席の確認 | 幹事 |
| 19:00 | 開会・乾杯のあいさつ | ○○課長 |
| 19:05 | 歓談 | |
| 20:30 | ラストオーダーの案内 | 幹事 |
| 20:50 | 締めのあいさつ | ○○部長 |
| 21:00 | 会費の確認・解散 | 幹事 |

## 終わったかどうかの確認方法
- [ ] 店に、確定の人数を伝えた
- [ ] 乾杯と締めのあいさつの人に、頼んである
- [ ] 進行表を、あいさつの人に送った
- [ ] 会費の集め方と、欠席時の扱いを案内に書いた
- [ ] 当日の領収書の宛名を確認した

## この手順が終わった人が、次に困ること
1回目がうまくいくと、次の飲み会の幹事も頼まれることが多いです。次に困るのは、**2次会をやるかどうか** と、**来年の幹事への引き継ぎ** です。今回の管理表と店の情報を1つのファイルに残しておくと、来年の自分か次の幹事が楽になります。
