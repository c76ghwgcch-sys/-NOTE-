# 長期休暇に入る前の、仕事の預け方

## いま、こんな場面で止まっていませんか
来月から休みに入ります。休み自体は決まりました。でも、自分しか分からない仕事がいくつもあります。誰に預ければいいのか。取引先にはいつ、どう伝えるのか。預けたあと、休み中に電話がかかってくるのではないか。考えるほど、「休む前に全部終わらせよう」と残業が増えていく。この記事は、休みの長さに合わせて仕事を預け、休み中は連絡が来ない状態を作るための手順です。

## この記事が向いていない人
- 休みの申請や手続きのやり方を知りたい人(この記事は、仕事の預け方だけを扱います)
- チーム全員が同じ仕事をしていて、誰でも代われる人
- 休みが3日以内の人

## 全体像：4ステップで終わります
1. 休みの3〜4週間前：預ける仕事を全部書き出す
2. 2〜3週間前：預け先を決めて、上司の了承をとる
3. 1〜2週間前：預け先に説明して、いっしょに1回やってみる
4. 前日まで：取引先へ連絡し、不在の設定をする

休みから戻ったときの受け取り方も、最後に書いています。

| ステップ | 終わったときに、決まっていること |
|---|---|
| 1 | 休みの期間にある仕事の全部 |
| 2 | 仕事ごとの預け先 |
| 3 | 預け先が1人でできる状態 |
| 4 | 取引先と社内への連絡 |

**休む前に全部を終わらせる必要はありません。** 仕事を「前倒し」「預ける」「止める」に分けると、休む前の残業がぐっと減ります。

かかる時間の目安は、ステップ1が1〜2時間、ステップ2が上司との相談30分、ステップ3が仕事1つにつき30分〜1時間、ステップ4が1時間ほどです。休みの1か月前から少しずつ進めれば、ふだんの仕事を止めずに終わります。

## 有料部分に入っているもの
- 1〜2週間／1か月程度／数か月以上で、何を変えるか
- 預ける仕事・止める仕事・前倒しする仕事の分け方
- 預け先の決め方と、上司への伝え方
- 取引先への連絡の順番
- そのまま使える書式3つ：不在時の連絡メール文例／預ける仕事の一覧表／戻ったときの確認リスト
- 休み中に連絡が来ないようにする方法

## 状況の分かれ方：休みの長さで、やり方が変わります

### Aの場合：1〜2週間
仕事の多くは **前倒しか、止める** で済みます。預けるのは、その期間にどうしても動かす必要がある仕事だけです。
取引先への連絡は、メールの不在通知とあわせて、主な相手に1回伝えれば足ります。

### Bの場合：1か月程度
月に1回の仕事が、必ず1回は来ます。**月次の仕事は、全部預け先を決める** 必要があります。
預け先といっしょに、1回は実際にやってみてください(ステップ3)。

### Cの場合：数か月以上
これは「預ける」ではなく **「引き継ぐ」** です。戻ったときに同じ仕事に戻るとは限りません。
- 取引先には、新しい担当者を正式に紹介します
- 書式2の一覧表は、手順まで書いた引き継ぎ資料にします
- 戻ったときの面談の日を、休みに入る前に上司と決めておきます

## ステップ1：預ける仕事を全部書き出す
休みの期間の予定を、カレンダーとメールから拾います。
1. カレンダーで、休みの期間に入っている予定を全部書き出す
2. 過去のメールで、去年の同じ時期に何をしていたかを見る
3. 毎月・毎週の決まった仕事を書き出す

書き出したら、書式2の一覧表で、1つずつ次の3つに分けます。
| 分け方 | 意味 | 例 |
|---|---|---|
| 前倒し | 休みの前に終わらせる | 来月分の資料の下書き |
| 預ける | 誰かに代わりにやってもらう | 毎週の数字の集計 |
| 止める | 戻るまで待ってもらう | 急がない改善の案件 |

**「止める」を増やすほど、預け先の負担が減ります。** 取引先や上司に「戻ってからでもいいですか」と聞くだけで、止められる仕事はけっこうあります。

## ステップ2：預け先を決めて、上司の了承をとる
預け先は、自分で勝手に決めずに上司に相談します。
上司に見せるのは、書式2の一覧表です。「この仕事を、△△さんにお願いしたいと考えています」と、案を持っていくと決まりやすくなります。

預け先を考えるときの目安：
- 同じ取引先と、すでにやりとりがある人
- 同じシステムやファイルを、すでに使える人
- 休みの期間に、その人自身の山場が重なっていない人

上司への伝え方の例：
「○月○日から休みに入ります。休み中の仕事をこの表にまとめました。週次の集計は△△さん、□□社の窓口は××さんにお願いしたいと考えています。ご意見をいただけますか」
表を見せながら、案を1つ持っていくのがポイントです。「どうしましょう」と聞くと、上司が一から考えることになり、決まるまで時間がかかります。

1人に全部を預けず、**仕事ごとに2〜3人へ分ける** と、1人の負担が大きくなりません。

## ステップ3：預け先に説明して、いっしょに1回やってみる
口で説明しただけでは、当日に手が止まります。1回は、預け先の人に **実際に手を動かしてもらい、自分は横で見る** 形でやってください。
そのとき、預け先がつまずいたところを、書式2の「注意点」の列に書き足します。

ファイルやフォルダの場所は、パスごと書きます。「いつものフォルダ」は、自分にしか分かりません。

### 休み中に連絡してよい場面を決めておく
預け先が迷ったときに、自分に連絡してよいかどうかを先に決めます。
| 場面 | 連絡してよいか |
|---|---|
| お金に関わる間違い(請求・支払い) | よい |
| 締切に間に合わない | よい(上司にも同時に) |
| やり方が分からない | 一覧表の注意点を見る。それでも分からなければ上司へ |
| 取引先からの問い合わせ | 預け先が答えられる範囲で答え、残りは「戻り次第」と返す |

## ステップ4：取引先へ連絡して、不在の設定をする

### 取引先への連絡の順番
1. 休み中に連絡が来そうな相手(進行中の案件)
2. 定期的にやりとりがある相手
3. それ以外は、不在通知で十分

1と2には、休みの1週間前までに、書式1の文例で個別に連絡します。

### メールの不在通知
Outlookでは「ファイル」→「自動応答」、Gmailでは「設定」→「不在通知」から設定できます【要確認：メールソフトのバージョンで画面名が変わる】。
不在通知には、**戻る日と、代わりの連絡先** を必ず書きます。

### チャットのステータス
社内チャットにも、休みの期間と代わりの担当者を書いておきます。

## 戻ったときの受け取り方
戻った日に、たまったメールを上から全部読むと、1日が終わります。
1. まず預け先と15分話して、休み中に起きたことを聞く
2. 書式3の確認リストを上から順に見る
3. メールは、自分あてで、まだ誰も返していないものだけを読む

戻った週は、新しい予定を入れすぎないようにします。休みに入る前に、戻った日から3日間の午前中を「確認の時間」としてカレンダーに入れておくと、会議で埋まるのを防げます。Bの場合とCの場合は、戻った週のうちに上司と15分話して、預けた仕事をいつ自分に戻すかを決めてください。

## つまずきやすい箇所と、その対処
| つまずき | 対処 |
|---|---|
| 休む前に全部終わらせようとして、残業が増える | 「止める」に回せないか、相手に聞く。全部を前倒ししない |
| 預け先から休み中に電話が来る | 「この場合はこうする」という判断の基準を、書式2の注意点に書いておく。連絡してよい場面も決めておく(例：お金や締切に関わる場合だけ) |
| 取引先が預け先ではなく、自分に連絡してくる | 連絡の文面に、代わりの担当者の名前・メール・電話を書く。CCに預け先を入れて送る |
| 戻ったら、やり方が変わっていた | 戻った日の15分の打ち合わせで、変わったことを先に聞く |

## そのまま使える書式3つ

### 書式1：不在時の連絡メール文例(Aの場合は短くしてよい)
```
件名：【ご連絡】○月○日〜○月○日 不在のお知らせ

いつもお世話になっております。○○社の○○です。
私事で恐縮ですが、下記の期間、不在にいたします。

不在期間：○月○日(○)〜○月○日(○)
期間中のご連絡先：△△(メール：xxx@xxx/電話：xx-xxxx-xxxx)

進行中の□□の件は、△△が引き継いでおります。
本メールのCCに△△を入れておりますので、以後のご連絡は△△までお願いいたします。

ご迷惑をおかけしますが、よろしくお願いいたします。
```

### 書式2：預ける仕事の一覧表(Bの場合は、月次の仕事をすべて入れる)
| 仕事 | 分け方 | 預け先 | 期限・頻度 | 使うファイルの場所 | 注意点・判断の基準 |
|---|---|---|---|---|---|
| 週次の数字の集計 | 預ける | △△さん | 毎週月曜 | ¥¥共有¥営業¥週次 | 数字が前週と2割以上違ったら課長へ |
| 来月の資料 | 前倒し | 自分 | 休み前日まで | | |
| 改善案の検討 | 止める | - | 戻ってから | | 先方了承ずみ |

### 書式3：戻ったときの確認リスト(Cの場合は、面談の日を書き足す)
- [ ] 預け先と15分話す(休み中の出来事、変わったこと)
- [ ] 一覧表の「預ける」の仕事が、全部終わっているか確認
- [ ] 「止める」にした仕事の相手に、再開の連絡
- [ ] 不在通知を解除する
- [ ] チャットのステータスを戻す
- [ ] 預け先にお礼を伝える

## 終わったかどうかの確認方法
休みに入る前日に、次のすべてに「はい」と言えたら終わりです。
- [ ] 一覧表のすべての仕事が、前倒し・預ける・止めるのどれかに分かれている
- [ ] 預ける仕事は、預け先が1回は自分で手を動かした
- [ ] 進行中の取引先に、個別に連絡した
- [ ] 不在通知に、戻る日と代わりの連絡先が入っている

## この手順が終わった人が、次に困ること
休みから戻った直後は、たまった連絡と、変わった仕事の両方が押し寄せます。次に困るのは、**戻ってからの最初の1週間で、何から手をつけるか** です。今回の一覧表は、そのまま戻ったときの順番表として使えるので、消さずに残しておいてください。
