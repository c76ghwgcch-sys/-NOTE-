# 柱④ 人事部（20本を超えてから・月1回・20分）

先に `sales/` に売上データ（記事ごとの購入数がわかるもの）を入れておきます。

## 毎月
```
フォルダの中の売上データと、全記事の本文を読んでください。

【1. 分類】
購入数の多い上位3本と、下位3本を挙げてください。
公開から1か月未満の記事は、集計から除いてください。

【2. 差の分析】
上位と下位で、次の8点がどう違うかを比べてください。

・テーマの種類(手順 / 書式 / 申請 / 設定 のどれか)
・読者が困っている場面の具体性
・状況の分かれ方が、いくつ書かれているか
・どの軸で分けているか(規模 / 時期 / 立場 / 状態)
・無料部分の文字数の比率
・無料部分に、有料側の中身の箇条書きがあるか
・書式や文例の数
・末尾に次の記事の案内があるか

推測ではなく、実際の本文から確認できた差だけを書いてください。差が見つからない項目は「差なし」と書いてください。

【3. 就業規則の更新】
2で見つかった差のうち、次の1本から再現できるものだけを、CLAUDE.md の【売れた記事の傾向】へ追記してください。既存の記述と矛盾する場合は、矛盾点を報告してから書き換えてください。

【4. 導線の張り直し】
下位3本の末尾に、上位3本のうち関連するものへの案内文を1〜2行で追加してください。選ぶ基準は「似ている記事」ではなく「この手順が終わった人が、次につまずくこと」です。
あわせて、どの記事にどれを案内したかの一覧を出してください。
どこからも案内されていない記事があれば、それも一覧にしてください。

【5. 読者が次に困っていること】
全記事の「次に困ること」を読んで、重複を除いて一覧にしてください。
そのうち、まだ記事にしていないものを分けてください。

最後に、CLAUDE.md をどう変更したかを3行以内で報告してください。
```

## 60本を超えたら、こちらも
```
過去3か月分の売上データを読んで、次を出してください。

1. 3か月とも上位にいた記事
2. 3か月とも下位だった記事
3. 1と2の差のうち、3か月とも一貫していた項目だけ

3で出たものだけを、CLAUDE.md へ追記してください。
1か月だけの差は、追記しないでください。
```

| 時期 | 頻度 | 見るもの |
|---|---|---|
| 20本未満 | 回さない | データが足りない |
| 20本から | 月1回 | 1か月分 |
| 60本から | 月1回 | 3か月分も見る |
