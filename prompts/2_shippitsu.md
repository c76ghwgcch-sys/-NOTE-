# 柱③ 執筆と検品（週1回・投げて離席）

下の枠の中をそのままClaude Codeに送ります。止まったら「続きから」と送ります。

```
企画で残した上位4テーマについて、CLAUDE.md の型どおりに本文を書いてください。

1テーマ1ファイル。ファイル名はテーマ名にする
4本まとめて作る。途中で確認は取らなくていい
有料ラインを引く位置に「ーーー ここから有料 ーーー」と書く
各ステップに、実際の画面名・ボタン名・入力例を必ず入れる
状況の分かれ方は、必ず3つ書く。2つで済ませない
書式や文例は、必ず3つ作る。本文を読まなくても単体で使える形にする
断定できない仕様には【要確認】を付ける
私の体験を入れる箇所に「[ここに体験]」と2か所書いて空けておく

【止まらないための条件】
・1本終わるごとに progress.md を更新すること。最後にまとめて書かない
・4本全部が終わるまで、私に確認しに来ないこと
・分からない項目は空欄にして、末尾に一覧にする。そこで止まらない
・途中で中断された場合、次に「続きから」と言ったら progress.md を読んで再開すること

4本を書き終えたら、続けてフォルダ全体を読み直し、次の6点で直してください。

重複: 他の記事とほぼ同じ説明をしている段落を、片方削るか案内文へ置き換える
中身のない文:「重要です」で終わっていて、次の行に具体的な作業がない箇所を全部リストにする
書式の数: 3つ未満になっている記事を一覧にする
分岐の数: 3つ未満になっている記事を一覧にする
語尾: 同じ文末が3回以上続いている箇所を直す
【要確認】: 付いている箇所を記事ごとに一覧にする。勝手に断定へ書き換えないこと

最後に、4本それぞれについて次を一覧で出してください。
・無料部分の文字数 / 全体の文字数 / その比率
・無料部分に、有料側の中身の箇条書きがあるか
・状況の分かれ方の数
・書式や文例の数
```

## 帰ってきたらやること
| やること | 時間 |
|---|---|
| 【要確認】のリストを見る | 20分 |
| [ここに体験] を8か所埋める(4本×2) | 40分 |
| noteに入れて、有料ラインを引く | 20分 |
